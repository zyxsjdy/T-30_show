What changes the estimate

Three switches change the high drone’s channel-strength score on data seed 14. Each bar is a mean over five reservoir seeds. Motion changes that score by more than the choice of estimator. The scores

A more negative NMSE is a tighter match to the true channel. −10 dB means the squared error is one tenth of the channel’s power. −20 dB is one hundredth. The picture scores and the chart above use different setups.

Words on this page

Channel estimation
Recovering the hidden multiplier that turned the sent pilot into the received one. With that multiplier, the receiver can read the data bits.
NMSE
Normalized mean squared error, shown in decibels. It compares the estimate with the true channel. More negative is tighter.
RIS
Reconfigurable intelligent surface: a panel of elements that can each change how they reflect a radio wave. Here each element uses a small random phase, at full reflection strength.
RF-QRC
The picture’s estimator. A short window of the received pilot becomes angles on a 5-qubit simulated circuit. Only the final linear fit is trained. The chart above compares a related vertical layout with a classical reservoir.
